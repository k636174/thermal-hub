# Thermal Hub 初期リリース仕様書

## 1. 目的

Thermal Hub は、利用者がネットワーク上の ESC/POS 対応サーマルプリンターを管理し、DB に保存した印字内容を必要な時に編集・送信できる Web ツールである。

## 2. 対象範囲

- Web 画面でのログイン／ログアウト
- CLI によるアカウント登録
- ログインアカウントごとの複数プリンター登録・編集・削除
- ログインアカウントごとの印字内容の登録・編集・削除
- 保存済み印字内容を、選択した登録済みプリンターへ TCP 送信
- 印字結果（成功／失敗、日時、メッセージ）の保存
- 年月を指定した月間カレンダーのサーマルプリンター印字
- 週を指定し、日別予定と反転日を編集できる週間スケジュールのサーマルプリンター印字

アカウントの Web 登録、画像印刷、印刷予約、プリンター状態監視、複雑な ESC/POS レイアウト編集は初期リリースの対象外とする。

## 3. 機能要件

### FR-01 認証

1. メールアドレスとパスワードでログインできる。
2. パスワードは安全なハッシュ形式で保存し、平文保存しない。
3. ログアウト時に認証セッションを破棄する。
4. ログイン画面以外の業務画面は未認証アクセスを拒否する。

### FR-02 CLI アカウント登録

1. `bin/cake user create <email> <name>` で登録を開始できる。
2. パスワードは対話入力し、8文字以上を要求する。
3. メールアドレスは一意とする。
4. 対話入力中のパスワードはコンソール画面へ表示しない。
5. CakePHP 5.4が提供しないAPIへ依存せず、WindowsとUnix系端末で非表示入力を行う。
6. Windowsでは最初の1文字で確定せず、Enterキーが押されるまで入力した全文をパスワードとして扱う。

### FR-02-1 CLI パスワードリセット

1. `bin/cake user reset-password <email>` で指定アカウントのパスワードを変更できる。
2. 新しいパスワードと確認値は対話形式かつ画面へ表示せずに入力する。
3. 新しいパスワードは8文字以上とし、確認値との一致を要求する。
4. 指定したメールアドレスのアカウントが存在しない場合は変更せずエラー終了する。
5. 成功時は新しいパスワードを安全なハッシュ形式で保存する。
6. Windowsでは最初の1文字で確定せず、Enterキーが押されるまで入力した全文を新しいパスワードとして扱う。

### FR-03 プリンター管理

1. 名称、ホスト名またはIPアドレス、TCPポート、文字エンコーディング、接続タイムアウトを登録できる。
2. 1アカウントに複数台登録できる。
3. CRUDは所有アカウントのデータだけを対象とする。
4. ポートは1～65535、タイムアウトは1～30秒とする。

### FR-04 印字データ管理

1. タイトルと本文を保存できる。
2. CRUDは所有アカウントのデータだけを対象とする。
3. 本文は必須で最大100,000文字とする。
4. 追加・編集画面から、保存前のタイトルと本文を別画面でプレビューできる。
5. プレビューは改行と空白を保持して表示し、入力内容を保存しない。プレビュー要求はCSRF保護されたPOSTとする。

### FR-05 印字

1. 保存済み印字データと登録済みプリンターを選択して即時印字できる。
2. UTF-8本文をプリンター設定のエンコーディングへ変換し、初期化、改行、紙送り、カット命令を付加してTCP送信する。
3. 接続または送信失敗は画面に表示する。
4. 成否、送信先、印字データ、実行日時、結果メッセージを履歴に保存する。
5. 他アカウントのプリンターまたは印字データは指定できない。
6. 印字画面では、用紙サイズの目安として「指定なし」「システム手帳 ナロー（170mm）」「M5／マイクロ5（105mm）」を選択できる。
7. 用紙サイズの選択は紙送り量やカット位置を固定せず、すべて本文の後に3行紙送りしてカットする。
8. 1行48桁（半角1桁、全角2桁）を基準に、入力行数、文字数、最大行幅、折り返し込みの推定行数を表示する。ナローは52行、M5は32行を印字可能範囲の参考上限として比較するが、超過時も印字を禁止しない。
9. QRコードを含む本文はQRコードの高さを行数・文字数だけでは判断できないため、範囲判定が参考値である旨を明示する。
9. CP932またはShift_JISで印字する場合は、ESC/POSの漢字コード体系をShift_JISに設定して漢字モードで本文を送信する。UTF-8の場合は漢字モード命令を付加しない。
10. 本文中の `!!文字!!` は、区切り記号を印字せず、囲まれた文字を白黒反転して印字する。
11. 本文中の `[[QR:内容]]` は、区切り記号を印字せず、内容をESC/POSのQRコードとして印字する。QRコードの内容はUTF-8とし、空の内容は通常の文字列として扱う。
12. 印字データの追加・編集画面には、選択文字を反転記法で囲む操作とQRコード記法を挿入する操作を設ける。
13. 保存前プレビューでは反転対象を反転表示し、QRコード記法をQR印字対象として明示する。入力した記法自体は保存時に変更しない。
14. 印字データの追加・編集画面にも用紙サイズの選択と印字範囲の参考情報を表示する。本文入力欄は選択した用紙の横幅と長さ（ナロー 80×170mm、M5 62×105mm）の比率・寸法を反映し、指定なしの場合は通常の入力欄とする。
15. 印字データごとに最後の印字操作で指定したプリンターと用紙サイズを、送信結果にかかわらず保存し、次回の印字画面および編集画面の初期値として使用する。保存済みプリンターが削除された場合はプリンターの記憶だけを解除する。機能追加前のデータは、最新の印字履歴にあるプリンターを初期値として引き継ぐ。
16. 印字データの記憶カラムを追加した環境では、マイグレーション時にCakePHPのモデルメタデータキャッシュを破棄し、追加カラムを直後のWebリクエストから保存・取得対象にする。
17. 開発用のDebugKitがインストールされていない本番環境では、設定にデバッグ有効値が残っていてもCLIを起動不能にせず、DebugKitを読み飛ばす。本番運用では別途デバッグを無効にする。
18. 印字データの追加・編集画面で保存した用紙サイズは、印字データ一覧の用紙サイズプルダウンへ反映する。一覧から別の用紙サイズで印字した場合は、印字データの用紙サイズもその選択へ同期する。

### FR-06 カレンダー

1. ログインユーザーはナビゲーションから月間カレンダー画面を開ける。
2. 年と月を指定して表示を切り替えられる。指定がない場合、または年が1900～2100、月が1～12の範囲外の場合は当月を表示する。
3. カレンダーは日曜始まりの7列・6週固定で表示し、対象月以外の日付も薄く表示する。
4. 前月・翌月へ移動でき、「今月」で当月へ戻れる。
5. 画像印字が有効な所有プリンターを選択し、カレンダーをESC/POSラスター画像として即時印字できる。
6. プリンター設定のDPIと印字可能幅を使い、ナローサイズの長さ170mmで、用紙の送り方向に対して横長のカレンダーを生成する。
7. カレンダー左側に5mm、カット側に20mmの安全余白を設け、土曜日の列と右端の罫線を先頭から150mm以内に収めてからカットする。
8. 他アカウントのプリンターは指定できず、送信の成否を印字履歴へ記録する。
9. 表の罫線は純黒の3dot、外枠は5dotで描画し、白黒ラスター変換後も明瞭に印字する。
10. カレンダー画面では、成否にかかわらず最後にカレンダーを印字した所有プリンターを初期選択する。該当プリンターが削除済み、または画像印字が無効な場合は初期選択しない。

### FR-07 週間スケジュール

1. ログインユーザーはナビゲーションから週間スケジュール画面を開ける。
2. 日付を指定すると、その日を含む月曜日から日曜日までの週を表示する。指定がない、または不正な場合は当週を表示する。
3. 前週・次週へ移動でき、「今週」で当週へ戻れる。
4. 7日それぞれに任意の予定を入力できる。予定は1日あたり120文字・6行以内とし、改行を保持する。
5. 7日それぞれに「反転」指定を設け、指定した日の曜日・日付を白黒反転して画面プレビューと印字へ反映する。印字時は反転文字列の前後に全角スペースを1文字ずつ加えて反転領域を広げる。初期状態では土曜日と日曜日を反転するため、祝日等も利用者が任意に追加・解除できる。
6. 所有プリンターを選択し、週間スケジュールをESC/POSテキストとして即時印字できる。画像化や回転は行わない。
7. 印字内容は期間ヘッダーを設けず、月曜日から日曜日までを上から順に、日付・英語3文字の曜日（Mon～Sun）と予定の組で出力する。日付行の右側には日の区切りを示す横線を印字する。日付部分は左位置を維持し、予定欄の各行は穴開け余白として行頭に全角スペース2文字を付ける。未入力行にも同じ全角スペースを送り、プリンターが空行を省略しないようにする。各日を日付1行・予定6行の固定高さとし、dot指定紙送りで7日分を先頭150mm以内に収める。実機補正として日曜欄の後に全角スペース入りの3行を追加し、その後へ20mmのカット余白を設ける。
8. 反転指定した日付・曜日にはESC/POSの白黒反転命令を使用し、予定本文は反転しない。
9. 他アカウントのプリンターは指定できず、送信の成否を印字履歴へ記録する。
10. プリンター設定の文字エンコーディングを使用し、CP932またはShift_JISでは漢字モードを有効にする。予定本文はESC/POS記法として解釈せず、そのまま文字として送信する。
11. 週間スケジュール画面では、成否にかかわらず最後に同機能で印字した所有プリンターを初期選択する。該当プリンターが削除済みの場合は初期選択しない。
12. 各日の予定と反転指定をログインユーザー・日付単位で保存でき、同じ週を再表示したときに復元する。保存操作だけを行う場合はプリンターを必要としない。
13. 印字操作時にも送信前の7日分を保存する。保存データの取得・更新はログインユーザーの所有データだけを対象とする。
14. 予定本文中の `!!文字!!` は、区切り記号を印字せず、囲まれた文字だけを白黒反転して印字する。

## 4. データモデル

- `users`: id, email, name, password, created, modified
- `printers`: id, user_id, name, host, port, encoding, timeout, created, modified
- `print_jobs`: id, user_id, title, body, paper_guide, last_printer_id, last_paper_guide, created, modified
- `print_logs`: id, user_id, printer_id, print_job_id, status, message, printed_at, created
- `weekly_schedule_entries`: id, user_id, schedule_date, note, is_inverted, created, modified

全ての外部キーにインデックスを設ける。ユーザー削除時は関連データを削除する。

## 5. 非機能要件

- CakePHP 5.4 / 64bit版PHP 8.2以上で動作する（Migrationsの14桁バージョンを扱うため）。
- DB変更はMigrationsで管理する。
- CSRF保護を有効にする。
- TCP接続は設定された短いタイムアウトで終了する。
- 所有者チェックをサーバー側で必ず実施する。

## 6. 受入条件

- CLIで作ったアカウントがログイン／ログアウトできる。
- 同一ユーザーが複数プリンターと複数印字データをCRUDできる。
- 別ユーザーのデータをURLやPOST値の改変で参照・更新・印字できない。
- 到達可能なTCPサーバーへESC/POSバイト列を送信でき、成功履歴が残る。
- 到達不能な送信先では失敗履歴が残り、エラーが表示される。
- 印字データの追加・編集画面で、未保存の本文を改行・空白を保持した状態でプレビューできる。
- 印字データの追加・編集画面で用紙サイズごとの参考上限を確認でき、本文欄が選択した用紙と同じ縦横比になる。
- 印字操作後に同じ印字データを再表示すると、送信結果にかかわらず直前のプリンターと用紙サイズが選択されている。既存データでは最新の印字履歴にあるプリンターが選択される。
- 印字画面で3種類の用紙サイズ目安を選択でき、本文の入力行数、文字数、最大行幅、折り返し込み推定行数と参考上限との比較が表示される。
- 目安を超える本文も印字でき、用紙サイズの選択にかかわらず本文後に3行紙送りして1回カットされる。
- QRコードを含む場合は、行数・文字数による判定ではQRコードの高さを保証できない旨が表示される。
- CP932／Shift_JIS設定のプリンターでは、日本語本文がShift_JISの漢字モード命令とともに送信される。
- `!!文字!!` と `[[QR:内容]]` を含む本文を印字すると、反転文字および読み取り可能なQRコード用ESC/POS命令へ変換される。
- 年月と所有プリンターを指定すると、該当月の横長カレンダーをサーマルプリンターへ印字でき、結果が履歴へ残る。
- 週、日別予定、反転日と所有プリンターを指定すると、月曜始まりの週間スケジュールをサーマルプリンターへ印字でき、結果が履歴へ残る。
- 週間スケジュールの予定と反転指定を保存すると、同じユーザーが該当週を再表示したときだけ入力内容が復元される。

## 7. 仕様変更手順

機能変更は、先に本書または `docs/specs/` 配下の差分仕様を更新し、受入条件を明記してから実装・テストを変更する。
