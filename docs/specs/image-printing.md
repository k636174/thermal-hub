# 画像アップロード印字

## 目的

ログインユーザーが画像をアップロードしてシステム内に保存し、登録済みの画像印字対応
ESC/POSプリンターへ再印字できるようにする。

## 仕様

- JPEG、PNG、WebP画像を受け付ける。拡張子ではなく実データから形式を判定する。
- 1ファイルの上限は20MBとする。
- Web実行環境のアップロード上限も20MB、POST全体の上限は22MB以上とする。
- 画像は一辺20,000px以下かつ4,000万画素以下とする。
- 保存名はシステムがランダムに生成し、元のファイル名は表示用メタデータとしてのみ保持する。
- 画像本体はWeb公開領域外の `storage/print-images` に保存する。
- 一覧、プレビュー、印字、削除はログインユーザーが所有する画像だけを対象にする。
- 印字時はEXIFの向きを反映し、縦横比を保ったままプリンターの印字可能幅と登録用紙長の両方に収まる最大サイズへ拡大または縮小し、白背景の二値画像へ変換する。
- ラスター画像の直後に全角スペースと改行を8行送る。CP932／Shift_JISでは漢字モードを有効にして文字コード変換し、画像末尾をカッター位置まで送ってからカットする。
- 画像ごとに最後に印字で選択したプリンターを記憶し、次回の初期選択にする。削除済みまたは画像印字が無効になったプリンターは選択しない。
- 画像印字が無効なプリンターは選択肢および送信対象にしない。
- 画像レコードを削除したときは保存ファイルも削除する。
- 印字結果は既存の印字ログへ `image` として記録する。送信内容そのものはログへ保存しない。

## 受入条件

1. 正常なJPEG、PNG、WebPをアップロードすると一覧へ表示され、再表示後もプレビューできる。
2. 20MB超、未対応形式、破損画像は保存されない。
3. 他ユーザーの画像はプレビュー、印字、削除できない。
4. 選択した画像印字対応プリンターへラスター形式のESC/POSデータを送信できる。
5. 画像を削除するとDBレコードと保存ファイルが削除される。
6. 一度プリンターを選んで印字すると、次回は同じプリンターが初期選択される。
